        Richtlijnen webservices

        Lees eerst onderstaande richtlijnen alvorens te starten met het gebruik van de webservices.

        Privacybewustzijn en regelgeving

        • Wanneer je gegevens exporteert via onze API of webservices dien je rekening te houden met de bescherming van persoonsgegevens.
        • Persoonsgegevens, zoals namen, adressen, e-mailadressen en IP-adressen, zijn gevoelige informatie. Je dient ervoor te zorgen dat deze gegevens veilig worden behandeld en voldoen aan de relevante privacywetgeving (AVG).
        • Je dient de gegevens op een legitieme en veilige manier te verwerken.
        • De toepassing die je ontwikkelt en aanbiedt is conform de Algemene Voorwaarden van Smartschool.

        Documentatie en hulpmiddelen

        • Raadpleeg steeds vooraf onze documentatie voor gedetailleerde informatie over de beschikbare eindpunten, parameters en authenticatiemethoden.

        Ondersteuning

        • Onze API en webservices bieden krachtige mogelijkheden om gegevens op te vragen en te wijzigen. We bieden geen support op de programmacode die je zelf ontwikkelt en zijn niet verantwoordelijk voor de kwaliteit en gevolgen van het gebruik ervan.
        • We verwachten dat je alle nodige technische kennis hebt alvorens te starten met de API of webservices. Indien dit niet het geval is, raden we je af om hiervan gebruik te maken.
        • Via onderstaande kanalen kan je in contact komen met andere scholen om zo kennis te delen over de werking van de API of webservices.
          • Smartschool Forum: www.smartschool.be/bb
          • Faceboekgroep ICT-coördinatoren of andere zelfhulpgroepen
        • We bieden geen bijkomend platform aan om je programmacode te testen. Je dient de ontwikkeling te doen door te gebruik te maken van je actueel Smartschool-platform.

        Instellingen webservices

        In dit dialoogvenster (Algemene configuratie > Webservices) kan je volgende opties instellen:

        • Wachtwoord: Dit is het globaal wachtwoord dat toegang geeft tot alle methodes (string $accesscode). Je kan het wachtwoord tijdelijk zichtbaar maken door op het oogje naast het wachtwoord te klikken. Via het kopieer-icoon kan je het wachtwoord naar je klembord kopiëren.
        • Doelgroep: De groep waarin de nieuw aangemaakte gebruikers terechtkomen.
        • Uniek veld: Kies gebruikersnaam of intern nummer. Afhankelijk van deze keuze zal Smartschool inkomende requests behandelen (string $userIdentifier).

        Het globaal wachtwoord verleent aan een externe toepassing automatisch toegang tot alle methodes. Dat is zeker niet altijd gewenst! Maak bij voorkeur een profiel aan met een apart wachtwoord voor beperkte toegang tot methodes.

        Globaal wachtwoord

        1. Kies in 'Algemene configuratie' voor 'Webservices'.
        2. Bekijk of wijzig het globaal wachtwoord bij 'wachtwoord' en klik eventueel op Opslaan.

        Profielen met beperkte toegang

        1. Kies in 'Algemene configuratie' voor 'Webservices'.
        2. Klik op 'Profiel toevoegen' om een nieuw profiel aan te maken.
        3. Vul de naam van het profiel in en duidt aan tot welke methoden dit profiel toegang heeft.
        4. Klik op Opslaan.

        Bezorg het wachtwoord van dit profiel aan de persoon die de externe toepassing beheert. Met dit wachtwoord heeft deze toepassing enkel toegang tot de door jou gekozen methodes.

        Detail van de methoden

        addCourse

        Met deze methode is het mogelijk om vakken aan te maken in Smartschool. Het XML-bestand heeft 3 parameters aan boord:

        • string $accesscode: Wachtwoord webservices
        • string $coursename: Vaknaam
        • string $coursedesc: Vakomschrijving
        • int $visibility: Zichtbaarheid (optioneel: '1' = zichtbaar (default) of '0' = niet zichtbaar)

        addCourseStudents

        Met deze methode is het mogelijk om bepaalde klassen toe te voegen aan een bepaald vak. Het XML-bestand heeft 4 parameters aan boord:

        • string $accesscode: Wachtwoord webservices
        • string $coursename: Vaknaam
        • string $coursedesc: Vakomschrijving
        • string $groupIds: CSV-lijst met unieke klas- of groepscode(s)

        addCourseTeacher

        Met deze methode is het mogelijk om een vakleerkracht toe te voegen aan een bepaald vak. Het XML-bestand heeft 5 parameters aan boord:

        • string $accesscode: Wachtwoord webservices
        • string $coursename: Vaknaam
        • string $coursedesc: Vakomschrijving
        • string $internnummer: Uniek veld gebruiker
        • string $userlist: CSV-lijst met uniek veld gebruiker

        addHelpdeskTicket

        Met deze methode is het mogelijk om een ticket aan te maken in de module Helpdesk. Gebruik de methode 'getHelpdeskMiniDbItems' om alle minidatabankitems op te halen die gebruikt kunnen worden in de module Helpdesk.

        • string $accescode: Wachtwoord webservices
        • string $title: titel van het helpdeskticket
        • string $description: omschrijving van het helpdeskticket
        • integer $priority: prioriteit van het ticket. Waarde tussen 1 en 5 (standaardwaarde is 3).
        • string $miniDbItem: item uit de minidatabank
        • string $userIdentifier: uniek veld gebruiker

        changeGroupOwners

        Met deze methode is het mogelijk om de klastitularissen van een klas te wijzigen.

        • string $accesscode: Wachtwoord webservices
        • string $code: Unieke klas- of groepscode
        • string $userlist: CSV-lijst met uniek veld gebruiker

        changeInternNumber

        Met deze methode is het mogelijk om het intern nummer van een gebruiker te wijzigen waarbij de gebruikersnaam als sleutelveld fungeert.

        • string $accesscode: Wachtwoord webservices
        • string $username: Gebruikersnaam
        • string $newInternNumber: Nieuw intern nummer

        changePasswordAtNextLogin

        Met deze methode verplicht je een bepaalde hoofd- of co-account om een nieuw wachtwoord in te stellen bij de volgende aanmelding.

        • string $accescode: Wachtwoord webservices
        • string $userIdentifier: uniek veld gebruiker
        • integer $accountType: type account ('0' = hoofdaccount, '1' = co-account 1, '2' = co-account 2…)
        Bij de eerste aanmelding dient het wachtwoord altijd gewijzigd te worden door de Smartschoolgebruiker. Sommige scholen gaan er vanuit dat dat via changePasswordAtNextLogin vermeden kan worden zodat het wachtwoord dat ingesteld werd door de beheerder behouden blijft. Dit is op geen enkele manier mogelijk.

        changeUsername

        Met deze methode is het mogelijk om de gebruikersnaam van een gebruiker te wijzigen waarbij het intern nummer als sleutelveld fungeert.

        • string $accesscode: Wachtwoord webservices
        • string $internNumber: Intern nummer
        • string $newUsername: Nieuwe gebruikersnaam

        checkStatus

        Met deze methode kan de status van de synchronisatieopdracht van de methode startSkoreSync opgevraagd worden.

        • string $accesscode: Wachtwoord webservices
        • string $serviceId: De unieke code van de synchronisatieopdracht van de methode startSkoreSync

        Deze methode geeft de status van de synchronisatieopdracht terug:

        • no_status: er is voor de opgegeven serviceId geen opdracht gevonden
        • busy: de opdracht is bezig
        • done: de opdracht is voltooid
        • error: de opdracht is niet voltooid door een fout tijdens de opdracht

        clearGroup

        Deze methode verwijdert alle gebruikers uit een groep.

        • string $accesscode: Wachtwoord webservices
        • string $group: Uniek klas- of groepscode
        • string $officialDate: Officiële datum (optioneel: zonder officiële datum dient de eventuele klasbeweging in Smartschool te worden bevestigd; formaat: YYYY-MM-DD)

        delClass

        Met deze methode kunnen groepen, klassen en officiële klassen uit Smartschool worden verwijderd. Deze methode kan aangeroepen worden met 1 extra parameter: $code. Dit volstaat om de groep te identificeren. De leden in deze groep worden niet uit Smartschool verwijderd.

        • string $accesscode: Wachtwoord webservices
        • string $code: Unieke klas- of groepscode

        delUser

        Deze methode verwijdert de opgegeven gebruiker uit Smartschool. Volgende gegevens zijn vereist:

        • string $accesscode: Wachtwoord webservices
        • string $userIdentifier: Uniek veld gebruiker
        • string $officialDate: Officiële datum (optioneel: zonder officiële datum dient de klasbeweging in Smartschool te worden bevestigd; formaat: YYYY-MM-DD)

        forcePasswordReset

        Met deze methode kan je voor een bepaalde gebruiker aangeven dat het wachtwoord verplicht gewijzigd dient te worden bij de eerstvolgende aanmelding.

        • string $accesscode: Wachtwoord webservices
        • string $userIdentifier: Uniek veld gebruiker
        • integer $accountType: Type account ('0' = hoofdaccount, '1' = co-account 1 of '2' = co-account 2 …)
